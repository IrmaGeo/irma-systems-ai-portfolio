# Irma Systems AI Portfolio

Modern React portfolio for Irma Modzgvrishvili, focused on enterprise systems, cloud integrations, AI-enabled workflows, and business systems analysis.

## Run locally

```bash
npm install
npm start
```

Open: http://localhost:3000

## Build

```bash
npm run build
```

## Deploy

Deploy this repository on Vercel by importing it from GitHub. Vercel will run the build automatically.
